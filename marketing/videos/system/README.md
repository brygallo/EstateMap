# Sistema compartido

Los archivos canónicos se mantienen en la raíz para que Claude y las personas los encuentren sin configuración adicional:

- `../product-context.md`: hechos verificables del producto.
- `../strategy.md`: públicos, pilares y experimentos.
- `../creative-system.md`: identidad visual y verbal.
- `../production-guide.md`: especificación de producción.
- `render-profiles.json`: perfiles técnicos ejecutables.
- `quality-rules.json`: controles automáticos mínimos.

No se copian dentro de cada video. Cada producción referencia esta base y conserva en `approval.json` el hash del plan aprobado.
