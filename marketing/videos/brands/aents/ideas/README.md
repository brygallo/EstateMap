# Ideas de video pendientes · Aents

Cada carpeta de aquí es una pieza **todavía no producida**: no tiene entrada en
`memory/catalog.json` ni carpeta en `library/`, y la fábrica no la conoce. Sirven
para no perder un guion o un ángulo mientras falta algo para poder construirlo
—normalmente componentes de animación, a veces una verificación del producto.

Una idea sale de aquí cuando alguien la ejecuta con la fábrica:

```bash
marketing/videos/video --brand aents new "<brief>" --duration <segundos>
```

A partir de ese momento la fuente de verdad es la carpeta de `library/`, y la
carpeta de esta idea se borra.
